# Dataset Card – Office Item Classification (PDE3802 Assessment 1, Part B)

## Summary
Single-object images of **7 office-item classes** for image classification:
`book`, `bottle`, `keyboard`, `mouse`, `mug`, `phone`, `stapler`.
Each image shows one item (a crop around the object), intended for training and
testing a classifier that recognises one office item at a time.

| | |
|---|---|
| Total images | 1,399 |
| Classes | 7 |
| Image format | JPEG, long side ≤ 512 px (Open Images crops) or 1280×720 (own photos) |

## Sources
1. **Open Images V7** (Google) – 1,344 crops.
   Images: CC BY 2.0 (as listed by Open Images); box annotations: CC BY 4.0.
   Each crop's original Open Images image ID and split are listed in
   `data/raw/openimages_sources.csv`.
   Open Images class names used: Book, Bottle, Computer keyboard, Computer mouse,
   Mug, Mobile phone, Stapler.
2. **Own photos** – 55 stapler photos taken by the team with a laptop webcam
   (`src/capture.py`) in two rooms (bedroom, session s01; kitchen, session s02),
   added because Open Images contains very few usable staplers.

## Collection process
- `src/download_openimages.py` reads the Open Images box annotations and keeps
  boxes of the 7 classes that are **not** "group-of" boxes or depictions
  (drawings, posters) and cover at least 2% of the photo.
- For each selected photo, the **largest** box of the class is cropped with a 10%
  margin and resized so the long side is at most 512 px. Only one crop per photo
  and class is kept, to maximise variety.
- Crops smaller than 64 px on the short side are discarded.
- Photos are chosen at random (seed 42) from the Open Images *train* split
  (200 per class) and *test* split (50 per class for book and bottle).
- Own stapler photos were taken in burst mode (one frame every 0.7 s) while the
  stapler and camera position were varied (angle, distance, surface, open/closed).

## Cleaning
Crops were inspected manually and removed if they showed the wrong object, were
unrecognisable (very dark, blurred or tiny), were mostly cut off, or showed several
items together.

## Splits
`src/split.py` creates train / validation / test folders:
- Crops from the **Open Images test split** always go to **test** (book, bottle).
- All other images are split **by group**, never image by image: all crops from the
  same source photo, and all own photos from the same capture session, go to the
  same split. This prevents near-identical images appearing in both training and
  test data, which would inflate the test score.
- Classes without Open Images test crops are split about 70 / 15 / 15 by group;
  book and bottle are split about 85 / 15 (train / val) plus their fixed test crops.

## Known limitations and biases
- **Class imbalance:** stapler has about half as many images as the other classes,
  and only two capture sessions of one stapler.
- **Mixed sources for stapler:** test staplers include a whole own capture session,
  which looks different from the Open Images staplers the model trained on.
- **Domain:** most images are internet photos (varied cameras, homes, offices,
  shops); few match a laptop webcam in an office, so live performance can differ
  from the test score.
- **Label noise:** Open Images boxes are partly machine-assisted; some wrong or
  ambiguous crops may remain after manual cleaning.
- **Context:** crops include some background (10% margin), so the model may partly
  use context (e.g. desks around keyboards).
- **No "no item" class:** every image contains one of the 7 classes, so the model
  always predicts one of them.

## Intended use
Teaching / coursework: training and evaluating an office-item classifier for the
PDE3802 autonomous office-robot design. Not intended for safety-critical use.
